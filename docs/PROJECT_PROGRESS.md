# Прогресс проекта

Оценка на 2026-10-24: **около 61% полного объёма проекта** (97 из 160 баллов).

Это предварительная инженерная оценка функционального покрытия по локальному коду, TECH_SPEC.md и накопленным результатам проверок. Это не процент затраченного времени, не точный подсчёт всех требований ТЗ и не подтверждение готовности production. Живые интеграции и развёртывание ещё не подтверждены. При уточнении требований оценка может уменьшиться.

## Правило расчёта

32 модуля из раздела 5 [ТЗ](../TECH_SPEC.md) и 8 дополнительных групп требований оцениваются с одинаковым весом. Группировка нужна для воспроизводимого укрупнённого отчёта; трудоёмкость модулей различается. Для каждой группы:

- **0** — рабочего пользовательского сценария нет.
- **1** — фундамент, модель данных или адаптер без полного сценария.
- **2** — работает часть требуемых сценариев, есть существенные функциональные пробелы.
- **3** — основной сценарий реализован и проверен локально; остаются расширения и/или live-проверка.
- **4** — весь согласованный объём группы реализован и проверен, включая необходимые реальные интеграции.

Формула: сумма баллов / (40 × 4) × 100, округление до целого. Сейчас: 97 / 160 = 60,625%, то есть **≈61%**. Небольшой завершённый этап может не изменить балл группы и общий округлённый процент. Проценты не увеличиваются автоматически после каждого изменения.

## Регулярные отчёты

В каждом отчёте о завершённом этапе указывать общий процент, проверенный результат и ближайший остаток. Текущую незавершённую проверку не учитывать как пройденную. Функциональное покрытие и готовность production сообщать отдельно.

Сверка 2026-10-24: клиентский портал, email-очереди, метрики YouTube и HeyGen BYOK расширили существующие группы, но их оставшийся объём пока не позволяет повысить баллы. Оценка сохраняется на 97/160 (≈61%). Инспекция зависимостей удаления аккаунта прошла локальные и браузерные проверки и не заменяет фактическое удаление.
