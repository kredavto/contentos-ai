# CONTENTOS AI

AI content operations SaaS. Implementation in progress; see [coverage and gaps](docs/IMPLEMENTATION_STATUS.md). The specification is not a claim of completed functionality.

Source: [kredavto/contentos-ai](https://github.com/kredavto/contentos-ai). Web deployment target: Vercel team digagency. Long-running media/queue processing runs as a separate service.

## Development
Node.js 22+ and pnpm 10.30.3. Tooling: `pnpm install`, `pnpm typecheck`, `pnpm lint`, `pnpm test`. Local runtime setup will be documented alongside the first persisted vertical slice.
